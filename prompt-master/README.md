# Prompt Master

Mod do Claude Code que melhora seus prompts antes de enviar.

- **Automático (padrão: ligado):** todo prompt digitado é reescrito por um modelo rápido (Haiku) para ficar mais claro, específico e com critérios de aceite, preservando intenção, nomes e código. Comece o prompt com `!` para enviar sem reescrever. Slash commands não são tocados.
- **Botão ✨ Prompt Master:** na faixa acima do campo de prompt; reescreve o rascunho dentro do campo para você revisar antes de enviar.
- **Auto: ON/OFF** na mesma faixa, ou `/prompt-master` para alternar.

## Instalação

```
/plugin install prompt-master --marketplace rgbotelho/GitHub
```

Responda `y` para adicionar o marketplace e escolha o escopo.
